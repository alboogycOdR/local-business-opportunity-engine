# Batch operator decision guide

- **Archive:** use when evidence is insufficient or policy/suppression blocks work; do not generate a demo.
- **Manual review:** use for ambiguity, weak source identity, or conflicting evidence; verify business-owned facts.
- **Audit required:** use when a website exists but no current audit supports a decision.
- **Score only:** use when the site is healthy or evidence does not justify a demo.
- **Generate demo:** use only when the brief supports `generate_demo` and facts are verified.
- **Conversion/technical offer:** use only when corresponding audit findings support it.
- **Do not contact / suppress:** use whenever suppression, consent, or policy requires it.
- **Regenerate/manual edit:** use for QA failures; never share the failed artifact.
- **Approve outreach:** only after QA, human review, source policy, readiness, and suppression checks pass.

Every decision needs evidence. LBOE does not send messages; manual outreach
happens outside LBOE; concept previews are not official websites.
