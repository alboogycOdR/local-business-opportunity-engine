# Current Limitations

- Audit screenshots and demo files use local filesystem storage only.
- Demos are not publicly hosted or deployed.
- LBOE does not send email, WhatsApp, SMS, or other outreach.
- There is no inbox synchronization or external CRM synchronization.
- The system does not provide legal or compliance determinations.
- Google Places enrichment is not implemented.
- Production website delivery and domain management are not implemented.
- The Operator UI is local-only and intentionally minimal; there is no public
  production dashboard.
- The Operator UI is local trusted mode; it is not production authentication
  or a public SaaS workspace.
- Preview links are controlled local/internal sharing, not production hosting.
- Demo generation uses deterministic templates only.
- Manual outreach and CRM events are trusted as operator-entered assertions.
- Pilot reports compute live from operational tables; they are not historical
  snapshots and current state counts differ from transition-event counts.
